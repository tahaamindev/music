Smart audio fallback (free YouTube API key)

When a video blocks embedding, T Music finds an embeddable alternate upload of the same song (re-upload, audio or lyric version) and plays that instead. It also checks all your links accurately and loads titles fast. Get a key: Google Cloud Console → enable "YouTube Data API v3" → Credentials → Create API key.

Unavailable songs

Songs YouTube won't play in an embedded player are flagged and skipped automatically.

Playback notes

Videos whose owners disabled embedding can't be played in any third-party player. T Music flags and skips them. Open this app from localhost or a web host (not as a plain file) so YouTube allows playback.
